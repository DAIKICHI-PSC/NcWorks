NcWorks V5.0.0

NC PROGRAM EDITOR, 2D SIMULATOR AND 2D CADCAM FOR SWISS-TYPE LATHE

Integrated NC Program Editor, 2D Simulator, and 2D CAD/CAM Software for Swiss-Type Lathes

Introduction

NcWorks is an integrated software designed for automatic lathes (Swiss-type lathes). It allows visual program creation and verification, contributing to significant time reduction (cost savings).

Commercially available CAD/CAM software is expensive and cannot simulate from NC code, which is why this program was created. It supports only the XZ plane and can be used to standardize NC programs.

Features

📝

NC Editor

Simultaneous editing of main and sub programs, syntax display, DXF export, auto-save and simulation execution

🚀

2D Simulator

Visual NC program verification, DXF tool shape import, real-time cutting simulation, dimension measurement

🏗

2D CAD/CAM

Auto-generate NC programs from DXF files drawn in CAD, convert tool paths layer by layer

DXF Export Function

Exporting NC programs to DXF files allows you to visually verify tool paths in CAD software.

In the output DXF file, each tool's path is output as a separate layer. G00 (rapid traverse) and G01/G02/G03 (cutting moves) are color-coded.

Output Format: Linear interpolation (G01) and arc interpolation (G02/G03) are output so they connect accurately. Material shape can also be output as DXF.

2D Simulator

A simulator that allows visual verification of NC programs. Ideal for training new employees and error prevention (poka-yoke).

Workflow

1
Create Program — Create an NC program in the editor, or load an existing program
2
Create Cutting Tool — Create a DXF file of the tool shape (refer to DXF files in sample_tools folder)
3
Register Cutting Tool — Register tools in the 2D simulator (first time only for each program)
4
Specify Material Diameter — Set the material diameter in the 2D simulator (first time only for each program)
5
Run Simulation — Set display and execution speed, press "Start" then "Next" to run (uncheck "Single Block" for fully automatic execution)
6
Dimension Measurement — After simulation completes, simple dimension measurement is available
How to Test: Load the program in the sample folder from the editor to test (the above settings are pre-configured). For internal machining tools such as drills, specify X0.

Dimension Measurement Function

After simulation is complete, dimension measurement is available with the following key operations:

KeyFunction
1Set measurement point 1
2Set measurement point 2
3Detect face and outer diameter positions

Measurement results are displayed in the lower-left panel. X coordinates, Z coordinates, and the distance between two points are calculated.

About X-axis Display: The NC X-axis value is treated as a diameter value and displayed as a radius value in the simulation. In measurement display, plus/minus are inverted to match NC standards.

2D CAD/CAM (DXF to NC Conversion)

Automatically generate NC programs from DXF files of tool paths drawn in CAD software.

Workflow

1
Draw Tool Paths in CAD — Draw each tool's path on separate layers (Zounou CAD RAPID 2D, JW_CAD, etc.)
2
Draw Circle at Start Point — Draw a CIRCLE at the start point of each path (diameter is arbitrary)
3
Save DXF File — Save as DXF with layer numbers assigned
4
Load in NcWorks — Load the DXF file with the "Load DXF Data" button
5
Set Conversion — Set feed rate, spindle speed, and dwell
6
Save NC Program — Save the generated NC program to a file

DXF Creation Rules

Required Rules

  • Each tool's path must be drawn on a separate layer (layer number required)
  • Draw a CIRCLE at the start point of each path (diameter is arbitrary)
  • Movements on the same coordinates cannot be converted (draw in a single stroke)

Supported Entity Types

  • LINE — Straight line (converted to G01)
  • ARC — Arc (converted to G02/G03)
About Single-Stroke Drawing: Normally, select No when asked "Is the line data drawn in a single stroke?"

Tool Data

How to Create DXF Tools

Create cutting tool shapes as DXF files. Follow the rules below:

  • Draw the tool cross-section shape (XZ plane)
  • Draw lines (LINE) or arcs (ARC) on a numbered layer name
  • Make the tool reference point (cutting edge) the starting point of the drawing
  • Draw as a closed shape (single stroke)
  • Unit is mm
Reference: Refer to the DXF files in the sample_tools folder to create your tool data.

Troubleshooting

Error Occurs During Simulation

  • Cause: R value not specified for G02/G03, or F value is 0
  • Solution: Always specify R value for arc interpolation and F value for cutting moves

Tool Is Not Displayed

  • Cause: DXF file is incorrect, or tool is not registered
  • Solution: Double-click in the tool list and select the correct DXF file

Simulation Freezes

  • Cause: Feed rate is too small with G98 (less than 0.001)
  • Solution: The system automatically limits to 0.001, but using G99 (feed per revolution) is recommended

Data Not Loaded in DXF Conversion

  • Cause: No CIRCLE at start point in layer, or no line segments
  • Solution: Ensure each layer has a CIRCLE (start point) and at least one line segment

Error When Zooming Too Much

  • Cause: Overflow (improved in V4.0.0)
  • Solution: Use V5.0.0

Nuitka Compiled Version Detected as Virus

  • Cause: Executable files compiled with Nuitka may be falsely detected
  • Solution: Add an exception in your security software to allow use
